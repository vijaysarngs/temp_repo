## Maintenance contract

This is the canonical project reference. When the project gains, removes, renames, or changes files, update this document in the same change. Future documentation updates should preserve the structure used here:

1. Update the repository map and file inventory.
2. Update the affected file section, including its folder, purpose, inputs, outputs, side effects, and dependencies.
3. Document every named function, method, nested helper, route, React component, and relevant inline callback.
4. Include every parameter, its default where applicable, the return value, and important validation or failure behavior.
5. Update data-model, API, configuration, artifact, and workflow sections when their contracts change.

Generated dependency lockfiles and generated evidence files are described as artifacts rather than expanded line by line. Secrets and local `.env` values must never be copied into this document.
Installed dependency trees, interpreter caches, test caches, and temporary Office lock files are transient local state and are excluded from the source-file inventory.

## 1. Project overview

The project provides an evidence-backed CVE processing pipeline:

1. A scanner CSV or XLSX is read and deduplicated by CVE.
2. Amazon Bedrock classifies source-supported product and component information.
3. A command-template agent proposes tightly restricted version-discovery commands for review.
4. A Flask API and React UI expose CSV upload, range selection, enrichment, preview, and download.
5. A separate MCP service gathers CVE evidence from live upstream sources, local Git mirrors, CSAF mirrors, and linked advisories.
6. Paramiko and Oracle examples provide a starting point for running reviewed commands and retaining server context.

## 3. Root Python modules

### `agent_utils.py`

- **Folder:** `/`
- **Purpose:** Supplies shared input-cleaning helpers and the single Bedrock invocation path used by both enrichment agents.
- **Depends on:** `boto3`, `botocore`, and `config.py`.

#### Functions

##### `clean(value)`

- **Parameters:** `value` — any value; dates and datetimes receive special handling.
- **Returns:** `""` for `None`, an ISO-8601 string for `date`/`datetime`, otherwise a stripped string.
- **Purpose:** Produces CSV/prompt-safe text without preserving surrounding whitespace.

##### `normalize_name(value)`

- **Parameters:** `value` — a column/header-like value.
- **Returns:** Lowercase, whitespace-normalized text with underscores and hyphens treated as spaces.
- **Purpose:** Makes header comparison tolerant of common formatting differences.

##### `get_value(row, *names)`

- **Parameters:** `row` — mapping of columns to values; `*names` — accepted aliases.
- **Returns:** The cleaned value of the first matching column, or `""`.
- **Purpose:** Retrieves a row field using normalized header matching.

##### `create_bedrock_client()`

- **Parameters:** None.
- **Returns:** A configured `bedrock-runtime` boto3 client.
- **Purpose:** Enforces `USE_BEDROCK`, applies region, optional explicit credentials, timeouts, and one standard retry attempt.
- **Failures/side effects:** Raises when Bedrock is disabled or client construction fails; logs initialization without printing secrets.

##### `invoke_bedrock(client, body, purpose="model request")`

- **Parameters:** `client` — boto3 Bedrock Runtime client; `body` — request payload mapping; `purpose` — log label.
- **Returns:** Parsed JSON response from the model.
- **Purpose:** Invokes `config.BEDROCK_MODEL_ID`, first requesting optimized latency and falling back to standard latency only when that option is unsupported.
- **Failures/side effects:** Logs timing and failures, then re-raises provider/network/JSON errors.

### `config.py`

- **Folder:** `/`
- **Purpose:** Loads `.env`, exposes Bedrock/AWS/NVD settings, and optionally imports settings from `aegis_core/aegis_core/config.py` under an isolated module name.
- **Functions/classes:** None.
- **Important values:** `NVD_API_KEY`, `USE_BEDROCK`, `BEDROCK_MODEL_ID`, `AWS_DEFAULT_REGION`, `AWS_ACCESS_KEY_ID`, and `AWS_SECRET_ACCESS_KEY`.
- **Behavior:** Adds the nested Aegis path to `sys.path`, defaults the provider/model and demo mode, strips quotes/whitespace from credentials, and deliberately tolerates missing optional dotenv/internal configuration.

### `cve_component_enrichment.py`

- **Folder:** `/`
- **Purpose:** Core evidence-backed classifier. It reads CSV/XLSX findings, groups observations per CVE, requests structured Bedrock classifications, validates every claimed label against exact source evidence, retries incomplete results, and writes diagnostics and component maps.
- **Primary contracts:** `COMPONENT_COLUMNS`, `FIELDS`, `KINDS`, accepted source-header aliases, CVE regex, JSON tool schema, and classification statuses.

#### Functions

##### `clean(value)`

- **Parameters:** `value` — any value.
- **Returns:** Empty text for `None`; otherwise stripped text.
- **Purpose:** Basic value normalization for ingestion.

##### `normalized(value)`

- **Parameters:** `value` — any source/evidence value.
- **Returns:** Unicode NFKC-normalized, whitespace-collapsed, case-folded text.
- **Purpose:** Enables strict formatting-insensitive comparisons without fuzzy semantic matching.

##### `header_key(value)`

- **Parameters:** `value` — header text.
- **Returns:** A `normalized` header with `_` and `-` converted to spaces.
- **Purpose:** Canonicalizes incoming column names.

##### `meaningful(value)`

- **Parameters:** `value` — candidate cell/label.
- **Returns:** `True` unless the normalized value belongs to the configured empty/sentinel set.
- **Purpose:** Rejects blank and placeholder values such as `n/a`, `unknown`, and `null`.

##### `get_value(row, *aliases)`

- **Parameters:** `row` — input mapping; `*aliases` — possible field names.
- **Returns:** First meaningful matching value, cleaned, or `""`.
- **Purpose:** Reads application/OS/etc. across scanner header variants.

##### `object_schema(properties)`

- **Parameters:** `properties` — JSON-schema property mapping.
- **Returns:** A closed object schema requiring every supplied property.
- **Purpose:** Builds the nested Bedrock tool-input schemas consistently.

##### `read_source_file(path, sheet_name=None)`

- **Parameters:** `path` — CSV/XLSX path; `sheet_name` — optional XLSX worksheet.
- **Returns:** List of row dictionaries.
- **Purpose:** Reads UTF-8 BOM-aware CSV or read-only/data-only XLSX.
- **Validation:** Requires an existing supported file, nonempty unique headers, correctly sized CSV rows, and at least one data row. XLSX requires `openpyxl`.

##### `build_records(rows)`

- **Parameters:** `rows` — source row mappings.
- **Returns:** `(records, skipped)` where records are deduplicated by CVE but retain sources, contexts, and every observation.
- **Purpose:** Extracts valid CVE IDs only from recognized ID columns, tracks row numbers, merges repeated application/OS contexts, and flags descriptions shared by several CVEs as ambiguous.

##### `classification_prompt(records, retry_feedback=None)`

- **Parameters:** `records` — eligible CVE records; `retry_feedback` — optional prior-result repair instructions.
- **Returns:** A complete text prompt plus JSON payload.
- **Purpose:** Constrains the model to exact, source-grounded product/component/symbol/path labels and treats record text as untrusted data.

##### `classify_batch(client, records, max_tokens=6000, retry_feedback=None)`

- **Parameters:** Bedrock `client`; `records`; output `max_tokens`; optional `retry_feedback`.
- **Returns:** Raw Bedrock tool-use response.
- **Purpose:** Invokes the configured model with the closed `submit_detailed_component_classifications` tool schema.

##### `require_keys(value, keys)`

- **Parameters:** `value` — candidate dictionary; `keys` — exact expected key collection.
- **Returns:** Boolean indicating an exact dictionary-key match.
- **Purpose:** Rejects missing and unexpected model fields.

##### `empty_result(cve_id)`

- **Parameters:** `cve_id` — normalized CVE identifier.
- **Returns:** Empty classification with all fact fields, `unknown` component kind, no issues, and `NEEDS_ENRICHMENT` status.
- **Purpose:** Supplies the safe default result.

##### `validate_fact(value, sources)`

- **Parameters:** `value` — one model fact (`label` plus evidence); `sources` — source-ID-to-text mapping.
- **Returns:** `(validated_fact, error_message)`; the fact is `None` on failure.
- **Purpose:** Enforces schema, meaningful labels, evidence presence, known source IDs, exact quote containment, label containment within the quote, and evidence deduplication.

##### `set_status(result)`

- **Parameters:** `result` — mutable validated classification.
- **Returns:** The same result after assigning `EVIDENCE_MISMATCH`, `SUPPORTED`, `PARTIAL`, or `NEEDS_ENRICHMENT`.
- **Purpose:** Centralizes normal classification-state calculation.

##### `validate_classification(item, record)`

- **Parameters:** `item` — one model-returned classification; `record` — corresponding source record.
- **Returns:** Validated result with issues/status.
- **Purpose:** Validates all fact fields and component kind; also prevents a protocol name alone from being treated as a version-bearing product.

##### `interpret_response(response, records)`

- **Parameters:** `response` — raw Bedrock response; `records` — requested records.
- **Returns:** Mapping of every requested CVE to exactly one validated/default result.
- **Purpose:** Extracts only the expected tool-use blocks and distinguishes missing, truncated, and duplicate output.

##### `merge_retry(previous, repaired)`

- **Parameters:** `previous` — first validated result; `repaired` — retry result.
- **Returns:** Merged result.
- **Purpose:** Retains earlier supported facts when a retry omits them and reports conflicting supported labels.

##### `classify_cves(client, records, batch_size=5, max_batches=None, max_tokens=6000, diagnostics=None, caller=None)`

- **Parameters:** Bedrock `client`; input `records`; `batch_size`; optional testing limit `max_batches`; `max_tokens`; mutable `diagnostics` list; injectable `caller` (defaults to `classify_batch`).
- **Returns:** CVE-to-classification mapping.
- **Purpose:** Marks missing/ambiguous input, processes eligible records in batches, records diagnostic responses/errors, and retries every non-supported record individually.
- **Nested helper `attempt(batch, feedback=None)`:** Calls the injected classifier and interpreter, appends diagnostics, and converts provider exceptions into per-CVE `MODEL_ERROR` results rather than losing the batch.

##### `result_reason(result)`

- **Parameters:** `result` — classification result.
- **Returns:** Joined issues, an explanation of missing labels, or a supported-but-host-unverified message.
- **Purpose:** Produces the human-readable reason column.

##### `component_rows(records, classifications)`

- **Parameters:** deduplicated `records`; `classifications` mapping.
- **Returns:** Sorted list of output dictionaries matching `COMPONENT_COLUMNS`.
- **Purpose:** Groups supported results by context/product/component/kind/status, keeps unresolved CVEs separate, and aggregates unique evidence, technical details, symbols, paths, CVE IDs, and source rows.

##### `write_csv(path, rows, columns)`

- **Parameters:** output `path`; dictionary `rows`; ordered `columns`.
- **Returns:** Nothing.
- **Purpose:** Writes UTF-8-with-BOM CSV with a header.

##### `positive_int(value)`

- **Parameters:** CLI text/value.
- **Returns:** Positive integer.
- **Purpose:** `argparse` type that rejects values below one.

##### `main()`

- **Parameters:** None directly; consumes CLI arguments.
- **Returns:** Nothing on success; raises/exits on invalid input/provider errors.
- **Purpose:** Coordinates input validation, deduplicated CSV output, conditional Bedrock client creation, classification, diagnostic JSON output, component CSV output, and summary logging.
- **CLI:** Positional `input_file`; optional `--sheet`, `--component-output`, `--deduplicated-output`, `--diagnostics-output`, `--batch-size`, `--max-batches`, and `--max-tokens`.

### `component_version_command_agent.py`

- **Folder:** `/`
- **Purpose:** Converts supported component-map rows into constrained, unexecuted server command templates. Bedrock selects an executable and approved version arguments; Python constructs the shell syntax.
- **Safety contracts:** Allowed `VERSION_ARGUMENTS`, dedicated no-argument scripts, prohibited executables, a closed probe schema, and separate path-discovery/version steps.

#### Functions

##### `server_shell(operating_system)`

- **Parameters:** target-server `operating_system` string.
- **Returns:** `"Windows CMD"`, `"POSIX shell"`, or `""` when unsupported/unknown.
- **Purpose:** Selects syntax from the remote server OS, not the local machine.

##### `generate_probe(client, row)`

- **Parameters:** Bedrock `client`; enriched component `row`.
- **Returns:** Tool input containing `version_target`, `executable`, `version_arguments`, `expected_result`, and `notes`.
- **Purpose:** Requests a simple version probe while prohibiting paths, package managers, network requests, mutations, and arbitrary shell code.
- **Failures:** Raises if Bedrock does not return the expected tool call.

##### `validate_probe(probe)`

- **Parameters:** candidate probe dictionary.
- **Returns:** Nothing when valid.
- **Purpose:** Requires exact fields/types, at most three allow-listed arguments, a safe executable basename, no blocked executable/package manager, and a version argument unless the executable is an approved dedicated version script.
- **Failures:** Raises `ValueError` for any rejected structure or command.

##### `build_commands(probe, shell)`

- **Parameters:** validated `probe`; normalized target `shell`.
- **Returns:** `(path_command, version_command)`.
- **Purpose:** Produces `where.exe` or `command -v` discovery plus a quoted `REPLACE_WITH_CONFIRMED_EXECUTABLE_PATH` version template. It never executes either command.

##### `read_enriched_csv(input_file)`

- **Parameters:** enriched CSV path.
- **Returns:** List of CSV row dictionaries.
- **Purpose:** Reads BOM-aware CSV and checks the required leading input columns and nonempty data.

##### `build_command_rows(rows)`

- **Parameters:** enriched component rows.
- **Returns:** Rows matching `OUTPUT_COLUMNS`.
- **Purpose:** Skips unsupported classifications/OSes, lazily creates one Bedrock client, generates and validates probes, attaches review guidance, and isolates per-row errors.

##### `write_command_csv(rows, output_file)`

- **Parameters:** generated `rows`; destination `output_file`.
- **Returns:** Nothing.
- **Purpose:** Creates parent folders and writes BOM-aware CSV in the fixed output-column order.

##### `main()`

- **Parameters:** None directly; reads CLI.
- **Returns:** Nothing.
- **Purpose:** Reads the enriched map, creates command rows, writes the result, and prints generated/total counts.
- **CLI:** Optional positional `input_file` (default `component_cve_map.csv`) and `--output`.

### `app.py`

- **Folder:** `/`
- **Purpose:** In-memory Flask API for the React UI. It accepts a CSV, retains a job by random ID, enriches a selected contiguous range, provides CSV downloads, and serves the built UI.
- **State/limits:** `JOBS` is process-local and nonpersistent; uploads are capped at 25 MiB; built assets are expected at `ui/dist`.

#### Functions and routes

##### `error(message, status=400)`

- **Parameters:** user-facing `message`; HTTP `status`.
- **Returns:** Flask JSON error response tuple.
- **Purpose:** Standardizes API failures.

##### `csv_response(rows, columns, filename)`

- **Parameters:** row dictionaries; ordered columns; download filename.
- **Returns:** Flask `Response` with UTF-8 BOM CSV and attachment header.
- **Purpose:** Builds downloadable CSV without a temporary file.

##### `upload_too_large(_exception)` — `RequestEntityTooLarge` handler

- **Parameters:** ignored Werkzeug exception.
- **Returns:** HTTP 413 JSON error.
- **Purpose:** Converts Flask’s upload-size exception into the API error shape.

##### `upload_csv()` — `POST /api/upload`

##### `enrich_range()` — `POST /api/enrich`

- **Parameters:** JSON `job_id`, one-based `start`, and positive `count`.
- **Returns:** Selected range metadata, output columns, and enriched rows.

- **Parameters:** path `job_id`; `kind` (`deduplicated` or `enriched`).

##### `health()` — `GET /api/health`

- **Parameters:** None.
- **Returns:** `{"status": "ok"}` JSON.
- **Purpose:** Lightweight process health check.

##### `frontend()` — `GET /`

- **Parameters:** None.
- **Returns:** Built `index.html` when available; otherwise JSON build instructions.
- **Purpose:** Supports serving the UI and API as one Flask application.

### `paramiko_ssh_runner.py`

- **Folder:** `/`
- **Purpose:** Security-conscious connection example for executing exactly one reviewed command on a directly reachable Linux server. Configuration constants must be replaced before use; passwords/passphrases are prompted, not stored.

#### Functions

##### `execute_command(client, command)`

- **Parameters:** connected Paramiko SSH `client`; reviewed remote `command` string.
- **Returns:** `(stdout_text, stderr_text, exit_code)`.
- **Purpose:** Starts a non-PTY command, closes stdin, drains stdout and stderr together, enforces a read deadline and combined output cap, and prevents stream-buffer deadlock.
- **Failures/side effects:** Raises on timeout/output overflow/SSH failure and always closes streams/channel.

##### `main()`

- **Parameters:** None; uses module configuration and interactive secret prompts.
- **Returns:** `0` for a zero remote exit code, otherwise `1`.
- **Purpose:** Validates placeholders/files/auth mode, optionally prefixes a safely quoted remote directory, rejects unknown host keys, connects with bounded timeouts and disabled agent/key discovery, runs the command, and prints both streams and exit code.

#### Inline callbacks

The JSX also defines short event/state callbacks; these are functions even though they are anonymous:

- Table pagination callbacks decrement/increment `page` within valid bounds.
- Drag-enter/drag-over/drag-leave/drop callbacks suppress browser defaults, toggle drag styling, and pass the first dropped file to `upload`.
- File-input change passes the selected file to `upload`; choose-file clicks the hidden input.
- `useMemo` returns enriched data only when that tab has data, otherwise deduplicated data or an empty table model.
- Upload success stores the returned dataset and initializes count to at most ten.
- Start/count input callbacks coerce values to positive in-range numbers and keep count valid after start changes.
- Quick-count callbacks pass 5, 10, 25, or `all` to `setQuickCount`.
- Tab callbacks select deduplicated/enriched views; enriched selection is guarded by available data.
- Error-dismiss clears the error string.

## 5. MCP evidence service

### `MCP/app/models.py`

- **Folder:** `/MCP/app`

#### Models

### `MCP/app/http.py`

- **Folder:** `/MCP/app`
- **Purpose:** Performs bounded public HTTP(S) retrieval while rejecting common SSRF targets and revalidating every redirect.

#### Data class

- **`FetchResult`:** Holds final `url`, `status_code`, `content_type`, and raw `body` bytes.

#### Functions and methods

##### `_blocked_ip(value: str) -> bool`

- **Parameters:** textual IP address.
- **Returns:** Whether it is private, loopback, link-local, multicast, reserved, or unspecified.
- **Purpose:** Central IP-address deny check.

##### `validate_public_url(url: str) -> None` (async)

- **Parameters:** candidate URL.
- **Returns:** Nothing when allowed.
- **Purpose:** Requires HTTP(S), a hostname, no embedded credentials, port 80/443/default, successful DNS resolution, and exclusively public resolved addresses.
- **Nested `resolve() -> set[str]`:** Synchronously calls `socket.getaddrinfo`; it is run in a worker thread to avoid blocking the event loop.

##### `SafeHttpClient.__init__(concurrency: int = 8)`

- **Parameters:** maximum simultaneous client operations.
- **Purpose:** Creates an `httpx.AsyncClient`, contact-bearing user agent, connect/request timeouts, manual redirects, and an asyncio semaphore.

##### `SafeHttpClient.close() -> None` (async)

- **Parameters:** None beyond `self`.
- **Purpose:** Closes the underlying HTTP connection pool.

##### `SafeHttpClient.get(url, *, params=None, headers=None) -> FetchResult` (async)

- **Parameters:** URL; optional query `params`; optional request `headers`.
- **Returns:** Final `FetchResult`.
- **Purpose:** Validates each URL/redirect, allows at most five redirects, raises for HTTP errors, enforces declared and streamed size limits, and returns collected bytes. Query parameters are cleared after a redirect.

### `MCP/app/adapters.py`

- **Folder:** `/MCP/app`
- **Purpose:** Normalizes CVE IDs and implements a common asynchronous `collect` convention for live and mirrored evidence sources.

#### Shared functions

- **Parameters:** candidate CVE ID.
- **Returns:** Stripped uppercase CVE ID.
- **Purpose:** Enforces `CVE-<4 digit year>-<at least 4 digit sequence>`.

- **Parameters:** CVE ID.
- **Returns:** `(year, bucket)` such as `("2024", "20xxx")`.

- **Parameters:** local mirror file path.
- **Returns:** Parsed JSON/YAML or plain text.

##### `build_adapters(config: dict[str, Any], data_dir: Path) -> list[Any]`

- **Parameters:** loaded source configuration and mirror data directory.
- **Returns:** Ordered instances of all eight live/special adapters plus `LocalMirrorAdapter`.
- **Purpose:** Defines the adapters run for each collection.

#### Adapter classes

Every `collect(cve_id: str, http: SafeHttpClient) -> list[SourceRecord]` method is asynchronous and returns zero or more normalized records:

- **`NvdAdapter.collect`:** Queries NVD CVE API 2.0; adds `NVD_API_KEY` when set; maps `vulnerabilities` entries.
- **`CveProjectAdapter.collect`:** Builds the CVE Project raw GitHub JSON path from `cve_bucket` and returns the document.
- **`GitHubAdvisoryAdapter.collect`:** Queries GitHub’s advisories API with API-version/accept headers and optional `GITHUB_TOKEN`.
- **`CisaKevAdapter.collect`:** Downloads the CISA Known Exploited Vulnerabilities feed and returns the matching `cveID`, if any.
- **`CertFrAdapter.collect`:** Searches CERT-FR avis/alerte indexes, follows up to 20 candidate JSON URLs per index, and verifies the returned advisory contains the CVE.
- **`JvnAdapter.collect`:** Checks year-specific and current JVN RDF feeds and returns feeds containing the CVE.
- **`TailscaleAdapter.collect`:** Checks the Tailscale security-bulletin XML index and returns it only when it contains the CVE.
- **`VendorVexAdapter.collect`:** Searches Red Hat, Microsoft, and SUSE `changes.csv` indexes, fetches up to the last two matching JSON paths per vendor, and isolates vendor-level failures.
- **`LocalMirrorAdapter.collect(cve_id, _)`:** Uses `rg` in a worker thread to find at most 100 matching JSON/YAML files under Git and CSAF mirror roots, parses them safely, and creates `mirror://` source URLs. The HTTP parameter is intentionally unused.

Additional constructors/helpers:

- **`VendorVexAdapter.__init__()`** initializes a per-base-URL in-memory index cache.
- **`VendorVexAdapter._index(base_url, http) -> str`** returns a cached `changes.csv` for up to one hour or fetches and caches a new copy.
- **`LocalMirrorAdapter.__init__(config, data_dir)`** retains the configuration/data root and sets the adapter display name.

## 8. End-to-end workflows

### Browser enrichment

1. `ui/src/App.jsx` sends a CSV to `POST /api/upload`.
2. `app.py` temporarily stores it, then `read_source_file` and `build_records` validate/deduplicate it.
3. The UI selects a one-based range and calls `POST /api/enrich`.
4. `classify_cves` batches Bedrock calls, validates source quotes, retries unresolved records, and `component_rows` builds the displayed map.
5. The UI previews and downloads deduplicated or enriched CSV from `/api/download/...`.

### Command-template generation

1. `component_version_command_agent.py` reads an enriched component CSV.
2. Unsupported classifications and unknown operating systems are skipped.
3. Bedrock proposes only an executable basename and approved version arguments.
4. Python validates the proposal and emits separate discovery and version templates.
5. A human must discover/confirm the actual executable path and review the command before any use.

### Independent evidence collection

1. `MCP/sync_sources.py` optionally refreshes Git and CSAF mirrors.
2. `EvidenceService.collect` queries live adapters and the local mirror concurrently.
3. It extracts advisory URLs, prioritizes a bounded set, and fetches them through `SafeHttpClient`.
4. `extract.py` creates typed, attributed snippets and the service removes duplicates.
5. The bundle is returned via MCP tools or written by `query_cve.py`.

### Review-gated remediation research

1. `Remediation_agent.py` loads a saved bundle or collects one through `EvidenceService`.
2. Source-specific compaction, OS-vendor filtering, ranking, and size limits produce the previewed evidence set.
3. No model call occurs unless the operator types `APPROVE` exactly.
4. Bedrock returns the closed remediation tool schema; the LangGraph validation node checks every factual claim against its cited excerpts.
5. Only verified candidates enter the Markdown report. The agent does not inspect an installed version, connect to a host, or perform a change.

## 9. Known operational notes

- `ui/README.md` currently names a Flask script that is not present; use `app.py` for this repository unless that documentation or file is corrected.
- `SUPPORTED` means the label is supported by supplied text. It does not prove that the component is installed, vulnerable, or unpatched on a specific host.
- Generated version commands are templates, not authorization to execute them.
- SSH host keys must already be verified and stored in the configured known-hosts file.
- Public evidence fetching is size-, redirect-, scheme-, port-, and IP-constrained, but production deployment should still use controlled egress and authentication.
- Remediation output is candidate research, not an applicability verdict: the agent has no installed-version/server state and intentionally performs no remediation.
